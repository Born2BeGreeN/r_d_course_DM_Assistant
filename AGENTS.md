# Project rules

- Implement the requested step and verify it; do not stop after proposing a plan.
- Preserve unrelated changes, original PDFs, manual labels, and historical results.
- Never invent source contents, annotations, measurements, or successful executions.
- Keep real keys out of chat, logs, and Git.
- Live external model calls occur only in steps explicitly requesting them; normal implementation checks use mocks.
- Explain outcomes and remaining manual actions in Ukrainian; use English identifiers and model prompts.
