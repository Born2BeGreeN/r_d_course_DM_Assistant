## Виправлення та вплив на evidence

1. **README:** прибрано взаємовиключні старі твердження «pipeline ще попереду», «labels pending», «v2 відсутній», Sol замість actual provider; додано actual online command, offline review, prerequisites/uv/Ollama/.env, provenance, outputs, historical-vs-current distinction та troubleshooting.
2. **`.gitattributes`:** `* -text` запобігає Git EOL conversion, яка могла б зламати byte-bound snapshot, code/prompt/annotation hashes на новому checkout. Binary PDF/SQLite позначено окремо. Не застосовувалося renormalize і не змінювалися frozen bytes. Це packaging fix, не нова нормалізація model input.
3. **`tests/test_submission.py`:** два focused regression tests працюють лише в isolated temporary Git repositories, без commits або model calls.
4. **Offline re-evaluation/audit outputs:** нові derived reports зберігаються окремо. Generation/scoring/data/schema/prompt/measurement policy не змінено; **жодна з 240 measurements не стала stale через цей audit, rerun не потрібний**.

Історичний `report_sha256` у [final integrity](../results/final/hw1_20261101/final_integrity.json) не збігається з пізнішою редакцією REPORT — це вже пояснено в REPORT; raw experiment checksums і повторні metrics збігаються. Не переписували старий audit задля нового editorial hash.

Зміна input/schema/prompt/generation settings/measurement policy потребує окремих generation reruns для affected rows; різні cohorts не змішувати.
- **Provenance/rights:** download URLs невідомі, author metadata і publication notices не є підтвердженням прав передати corpus/raw results. Узгодити допустимий пакет із власником матеріалів.

- **Coverage/generalization:** 10 golden, один observation/config, curated corpus, переважно English; selection на golden не є незалежним production test. П'ять label-policy conflicts не приховуються average score.

Завершеність експерименту — **complete**; готовність до review — **із зауваженнями**. Платний benchmark під час audit **не запускався**.
